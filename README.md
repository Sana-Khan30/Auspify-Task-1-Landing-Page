# Task 1: Responsive Landing Page — Auspify Technologies Internship

A modern, fully responsive landing page (**NovaFlow**) built using **HTML5**, **CSS3**, and **Vanilla JavaScript** as part of the **Auspify Technologies Internship**.

## 🚀 Key Features
- **Responsive Layout**: Built with CSS Grid, Flexbox, and fluid typography (`clamp()`) for seamless desktop, tablet, and mobile experiences.
- **Interactive Navigation Menu**: Sticky glassmorphism header, ScrollSpy active link highlighting, and mobile hamburger drawer menu.
- **Call-to-Action (CTA) & Forms**: Interactive signup modal and email newsletter validation.
- **Animations & Dynamic UI**:
  - Scroll-reveal animations powered by `IntersectionObserver`
  - Animated number counters
  - Interactive `7D` / `30D` live chart switcher
  - `Monthly` / `Annual` pricing toggle
  - Expandable FAQ accordion
  - Persistent Dark / Light theme toggle

## 🛠️ Tech Stack
- **HTML5** (Semantic structure & accessibility)
- **CSS3** (Custom properties, Grid, Flexbox, Media Queries, Keyframe Animations)
- **JavaScript (ES6+)** (DOM manipulation, IntersectionObserver, LocalStorage)
